# 设备实测与协议说明

> 测试日期：2026-11-24  
> 测试对象：ZDT 闭环步进驱动器（COM19，地址 2，115200 8N1，校验字节 0x6B）  
> 以下为实测结果，不同固件/型号可能不同；本仓库的系统状态页已兼容 Emm 31 字节和 X 37 字节两种 0x43 布局。

## 1. 0x43 系统状态（本机为 31 字节 Emm 布局）

发送：

```
02 43 7A 6B
```

实测返回（31 字节）：

```
02 43 1F 09 2E 35 00 00 05 C0 00 00 2E 6A 70
00 00 00 00 00 2E 6A 70 00 00 00 00 00 03 83 6B
```

字段偏移（完整帧）：

| 偏移 | 字段 | 说明 |
|---|---|---|
| 0 | 地址 | 0x02 |
| 1 | 功能码 | 0x43 |
| 2 | 总字节数 | 0x1F = 31 |
| 3 | 参数个数 | 0x09 |
| 4..5 | 母线电压 | mV，示例 0x2E35 = 11829 mV |
| 6..7 | 相电流 | mA |
| 8..9 | 编码器线性值 | 0..65535 |
| 10 | 目标位置符号 | 0=正，1=负 |
| 11..14 | 目标位置 | u32 |
| 15 | 转速符号 | 0=正，1=负 |
| 16..17 | 转速 | u16，RPM |
| 18 | 实时位置符号 | 0=正，1=负 |
| 19..22 | 实时位置 | u32 |
| 23 | 位置误差符号 | 0=正，1=负 |
| 24..27 | 位置误差 | u32 |
| 28 | 回零状态 | bit2 回零中，bit3 回零失败 |
| 29 | 电机状态 | bit0 使能，bit1 到位，bit2 堵转，bit3 堵转保护，bit7 掉电 |
| 30 | 校验 | 0x6B |

Emm 的 0x43 没有母线电流、编码器原始值、温度字段；X 固件的 0x43 为 37 字节，工具按帧长自动切换解析。

## 2. 命令支持情况（本机实测）

| 命令 | 结果 | 说明 |
|---|---|---|
| 0x3A 电机状态 | 有应答 | `02 3A xx 6B` |
| 0x3B 回零状态 | 有应答 | `02 3B xx 6B` |
| 0x36 实时位置 | 有应答 | 符号 + u32 |
| 0x33 目标位置 | 有应答 | 符号 + u32 |
| 0x34 实时目标位置 | 有应答 | 符号 + u32 |
| 0x35 转速 | 有应答 | 符号 + u16 |
| 0x37 位置误差 | 有应答 | 符号 + u32 |
| 0x24 母线电压 | 有应答 | u16 mV |
| 0x27 相电流 | 有应答 | u16 mA |
| 0x31 编码器线性值 | 有应答 | u16 |
| 0x32 输入脉冲数 | 有应答 | 符号 + u32 |
| 0x43 系统状态 | 有应答 | 31 字节 Emm 布局 |
| 0x42 驱动参数 | 有应答 | 33 字节，21 项 |
| 0x21 PID | 有应答 | 15 字节，3 个 u32 |
| 0x22 回零参数 | 有应答 | 18 字节 |
| 0x3C 双状态 | **不支持** | 返回 `02 00 EE 6B` |
| 0x1A 选项参数 | **不支持** | 返回 `02 00 EE 6B` |
| 0x3D IO 电平 | **不支持** | 返回 `02 00 EE 6B` |
| 0x26 母线电流 | **不支持** | 返回 `02 00 EE 6B` |
| 0x39 温度 | **不支持** | 返回 `02 00 EE 6B` |
| 0x41 位置窗口 | **不支持** | 返回 `02 00 EE 6B` |
| 0x1F 版本 | 有应答 | 只有 5 字节：`02 1F 05 82 6B` |

因此本工具：

- 系统状态用 `0x43`，不依赖 `0x3C`；
- 回零/电机状态用 `0x3B` + `0x3A`；
- 温度、母线电流等不支持项显示“-- / 不支持”，不是通信失败；
- `0x42` 只有 21 项，驱动参数页按 24 项布局解析不匹配时只读显示原始帧，避免误写。

## 4. 安全提示

- 接线、拔插电机线/通讯线前先断电。
- 第一次调试先空载、低速、小电流；确认急停/断电方式。
- RS485 长距离注意共地、A/B 双绞，必要时加 120Ω 终端电阻。
- 修改驱动参数/回零参数前先读取确认；不确定的项不要盲目写入。
