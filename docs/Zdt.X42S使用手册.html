1. 概述与文件结构

1.1 本库是什么

Zdt.X42S 是一个纯 C# 的串口通讯库，用于在 WinForms / WPF / 控制台程序中控制 ZDT X42S 第二代闭环步进电机。它把《ZDT_X42S 用户手册 V1.0.4》第 4、5 章的命令封装成了 普通 C# 方法，界面代码不需要自己拼字节、算校验或解析返回帧。

典型用途：云台俯仰/旋转轴、3D 打印设备、写字机、雕刻机、机械臂、电动夹爪、PLC 配套上位机。

1.2 协议范围

项目说明
通讯方式串口 TTL / RS232 / RS485；默认 115200、8 数据位、无校验、1 停止位
协议ZDT 串口自由协议：[地址][功能码][数据...][校验]
校验固定 0x6B（默认）、XOR、CRC-8；不支持 Modbus-RTU / CAN / DMX512
固件Emm5.0 与 X 两种固件都支持；两者部分命令格式不同
电机地址1-255，0 为广播地址；出厂默认 1
多机RS485 可一条总线接多台；也支持 0xAA 多电机命令和 0xFF 同步启动

2. 快速开始

2.1 接线与驱动器设置

项目推荐值 / 说明
供电常规版 10-29V，高压版 10-48V；建议 3A 以上电源，先接电机再接电源
串口参数115200、8、None、1；可在驱动器 UartBaud 菜单修改
校验方式Checksum = 0x6B（出厂默认）；本库也支持 XOR、CRC-8
电机地址ID_Addr = 1（出厂默认）；RS485 多机时每台设为不同地址
控制应答Response = Receive（默认）；如果改成 None，需要设置 bus.WaitForAck = false
固件识别小屏第二行显示 0.00err 且绿灯常亮 = Emm；显示 0.0° 且绿灯 1 秒闪 1 次 = X
校准新板或拆装过电机，先执行一次空载校准 Cal_MFL，否则精度和闭环效果会差
TTL 与 RS485：TTL 一般是单机点对点，一个串口接一个电机；RS485 可以一条总线挂多台， 但必须共地、A/B 不接反，长距离或高波特率时建议加 120Ω 终端电阻。USB 转 485 模块建议使用带自动收发切换的型号。

2.2 在 WinForms 项目中引用

方式一（推荐）：把 src\Zdt.X42S\Zdt.X42S.csproj 添加到你的解决方案，然后右键你的 WinForms 项目 → 添加 → 项目引用。

方式二：直接引用 DLL。根据项目框架选择：

你的项目引用这个 DLL
.NET Framework 4.8 WinFormslib\net48\Zdt.X42S.dll（不需要额外 NuGet 串口包）
.NET 8 / .NET 9 WinFormslib\netstandard2.0\Zdt.X42S.dll 或 lib\net9.0-windows\Zdt.X42S.dll

.NET Core / .NET 5+ 项目还需要 System.IO.Ports NuGet 包；如果你引用的是项目，包会自动带过来。

2.3 最小可运行代码

using Zdt.X42S;

// 1. 打开串口（一条总线可以挂多台电机）
var bus = new ZdtSerialBus();
bus.Open("COM3", 115200);

// 2. 创建电机对象：地址 1，出厂默认 Emm5.0 固件
//    如果是 X 固件，改成 ZdtFirmware.X
var motor = bus.CreateMotor(1, ZdtFirmware.Emm);

// 3. 使能、调速、停止
motor.Enable();                       // 锁轴
motor.RunVelocity(500, 2000);         // 500RPM，加速度 2000RPM/s
System.Threading.Thread.Sleep(3000);  // 演示用，实际界面不要 Sleep
motor.Stop();                         // 立即停止
motor.Disable();                      // 松轴

// 4. 关闭
bus.Close();
不要用 Sleep 卡住界面：示例里的 Sleep 只是为了演示。WinForms 中请把连续读取交给 ZdtPoller，按钮里只发短命令；需要等待动作完成时用 PositionReached / HomingCompleted 事件。

2.4 WinForms 实时显示位置和速度

ZdtSerialBus _bus;
ZdtMotor _motor;
ZdtPoller _poller;

private void Form1_Load(object sender, EventArgs e)
{
    _bus = new ZdtSerialBus();
    _bus.Open("COM3", 115200);
    _motor = _bus.CreateMotor(1, ZdtFirmware.Emm);

    _poller = new ZdtPoller(_motor, 100);   // 100ms 采一次
    _poller.Updated += (s, snap) =>
    {
        lblPosition.Text = snap.PositionDegrees.ToString("F2") + " °";
        lblSpeed.Text    = snap.SpeedRpm.ToString("F1") + " RPM";
        lblState.Text    = snap.MotorStatus.IsEnabled ? "使能" : "失能";
    };
    _poller.Start();
}

private void Form1_FormClosing(object sender, FormClosingEventArgs e)
{
    if (_poller != null) { _poller.Stop(); _poller.Dispose(); }
    if (_bus != null) _bus.Close();
}

ZdtPoller 在 UI 线程创建时，会自动把 Updated 事件 Post 回 UI 线程； 如果你在后台线程创建它，事件就在后台线程触发，需要自己 BeginInvoke。

2.5 关闭顺序

  1. 先 poller.Stop()，停止后台串口读取；
  2. 再 motor.Dispose()（可选，主要是取消事件订阅）；
  3. 最后 bus.Close() 关闭串口。

顺序反了可能出现“后台线程还在读已关闭串口”的异常；库内部已经做了保护，但按这个顺序最干净。

3. 核心类说明

3.1 ZdtSerialBus（一条串口总线）

成员说明
Open(portName, baudRate)打开串口并启动接收线程；默认 115200
Close() / Dispose()停止接收线程并关闭串口
CreateMotor(address, firmware)创建绑定到该总线的电机对象
ChecksumModeFixed6B / Xor / Crc8，必须和驱动器 Checksum 菜单一致
TimeoutMs等待应答超时，默认 200ms
WaitForAck控制命令是否等待 0x02 应答；驱动器 Response=None 时设为 false
InterCommandDelayMs命令间隔，默认 2ms；RS485 转换器较慢时加大
FrameReceived收到任意一帧时触发（后台线程池线程）
ErrorOccurred接收线程异常时触发
SendCommandAsync()异步发送并等待应答，不阻塞界面
SendMultiMotorCommand()发送 0xAA 多电机命令

3.2 ZdtMotor（单台电机）

成员分组常用方法
连接属性Address、Firmware、Microstep、MotorStepAngleDegrees、XPositionUnitDegrees
使能/停止Enable()、Disable()、Stop()
速度RunVelocity(rpm, accel)、SetSpeedEmm()、SetSpeedX()、SetSpeedXWithCurrent()
位置MoveAbsoluteAngle()、MoveRelativeAngle()、MoveToAngle()、MovePositionEmm/X...
回零Home()、SetHomingZero()、AbortHoming()、SetHomingParameters()
读数ReadPositionDegrees()、ReadSpeedRpm()、ReadMotorStatus()、ReadSystemState() 等
参数SetMicrostep()、SetAddress()、SetClosedLoopCurrent()、SetPidEmm/X() 等
事件ActionCompleted、PositionReached、HomingCompleted、FrameReceived

3.3 ZdtPoller（后台轮询）

每 intervalMs 读取一次“回零状态 + 电机状态 + 实时位置 + 实时转速”，通过 Updated 事件返回 ZdtMotorSnapshot。建议间隔 50-500ms；不要低于 20ms， 否则串口会被轮询占满，按钮命令会排队。

3.4 ZdtProtocol（协议工具箱）

如果需要自己发命令或做协议分析，可以使用：

  • ZdtProtocol.BuildFrame(address, code, checksum, data...) 组帧；
  • ZdtProtocol.ComputeChecksum / ComputeCrc8 计算校验；
  • ZdtProtocol.TryParseFrame 从字节流拆帧；
  • ZdtProtocol.ToHexString / ParseHexString 十六进制日志；
  • ZdtProtocol.DegreesToPulses、EmmRawToDegrees 等单位换算。

3.5 数据模型

类型内容
ZdtMotorStatus使能、到位、堵转、堵转保护、左右限位、掉电标志
ZdtHomingStatus编码器正常、已校准、正在回零、回零失败、过温、过流
ZdtSystemState母线电压/电流、相电流、编码器、目标/实时位置、转速、误差、温度、状态
ZdtHomingParameters回零模式、方向、速度、超时、碰撞检测转速/电流/时间、上电自动回零
ZdtPidEmm / ZdtPidX两种固件的 PID 参数
ZdtMotorSnapshot轮询快照：位置、转速、电机状态、回零状态、时间

4. 运动控制

4.1 使能与失能

motor.Enable();    // 锁轴，电机保持力矩
motor.Disable();   // 松轴，可以用手拧动（注意负载可能掉落）

失能后电机不再保持位置；云台俯仰轴失能前请确认机械结构不会因重力下落。

4.2 速度模式

// 正数 CW，负数 CCW；加速度单位 RPM/s；rpm=0 会自动停车
motor.RunVelocity(500, 2000);    // 500RPM，2000RPM/s 加速
motor.RunVelocity(-300, 1000);   // 300RPM 反转，1000RPM/s 加速
motor.Stop();
固件库内部发送单位
Emm5.00xF6，方向 + 速度 + 加速度档位速度 RPM；加速度 0-255 档位（库会从 RPM/s 换算）
X0xF6，方向 + 加速度 + 速度速度 0.1RPM；加速度 RPM/s

需要精确控制 Emm 的加速度档位时，用 SetSpeedEmm(dir, rpm, acc, sync)。

4.3 位置模式

// 绝对角度：相对坐标零点
motor.MoveAbsoluteAngle(90, 300, 1500);

// 相对角度：相对当前实时位置
motor.MoveRelativeAngle(-10, 200, 1000);

// 完整参数：角度、速度、加速度、运动方式、是否多机同步、X 固件最大电流
motor.MoveToAngle(
    degrees: 45,
    speedRpm: 300,
    accelerationRpmPerSecond: 1500,
    motionMode: ZdtMotionMode.Absolute,
    synchronized: false,
    maxCurrentMa: 2000);   // 仅 X 固件有效，0 表示不限流
项目说明
运动方式RelativeToLastTarget 相对上一次目标；Absolute 相对零点；RelativeToCurrent 相对当前实时位置
Emm 固件库把角度换算成脉冲数：1.8° 电机、16 细分时 3200 脉冲/圈；0.9° 电机为 6400
X 固件位置单位为 0.1°；默认 90° 发送 900。如果驱动器开启 S_PosTDP（再缩小 10 倍），设置 motor.XPositionUnitDegrees = 0.01
方向正角度 CW，负角度 CCW；方向是相对驱动器“电机运动正方向”设置
命令打断X42S/Y42 支持位置命令打断：运动过程中再发新位置命令，会平滑过渡到新目标
位置模式到位后，如果驱动器 Response 设为 Reached/Both/Other，会主动返回 地址 + FD + 9F + 6B，库会触发 PositionReached 事件。 默认 Receive 模式只返回 0x02，不会主动返回到位帧。

4.4 回零

模式枚举说明
单圈就近Nearest (0)转到最近的原点，默认模式
单圈方向Direction (1)按设定方向找原点
多圈无限位碰撞SensorlessCollision (2)撞到机械限位后，以堵转位置为零点
多圈限位开关EndStop (3)接限位开关回零
绝对坐标零点AbsoluteZero (4)回到坐标零点
上次掉电位置PowerLossPosition (5)Y42 / 带掉电记录电池时有效
// 先把当前位置设为单圈零点（会写入驱动器）
motor.SetHomingZero(store: true);

// 触发碰撞回零；回零完成后触发 HomingCompleted 事件
motor.Home(ZdtHomingMode.SensorlessCollision);

// 回零卡住/需要取消
motor.AbortHoming();

碰撞回零前，先在驱动器里设置好回零速度、碰撞检测电流和时间；参数可用 SetHomingParameters() 修改。回零完成帧为 地址 + 9A + 9F + 6B。

4.5 停止、多机同步与多电机命令

// 立即停止本机
motor.Stop();

// 两个轴分别缓存一条位置命令，然后用广播地址同时启动
m1.MoveAbsoluteAngle(30, 200, 1000, ZdtMotionMode.Absolute, synchronized: true);
m2.MoveAbsoluteAngle(60, 200, 1000, ZdtMotionMode.Absolute, synchronized: true);
m1.TriggerSyncMotion();   // 内部用 0x00 FF 66 6B 广播

// 一条串口帧同时发给多个地址（0xAA 多电机命令）
byte[] cmd1 = ZdtProtocol.SpeedEmm(1, ZdtChecksumMode.Fixed6B, ZdtDirection.Cw, 500, 50, false);
byte[] cmd2 = ZdtProtocol.Read(2, ZdtChecksumMode.Fixed6B, 0x36);
bus.SendMultiMotorCommand(cmd1, cmd2);
0xAA 多电机命令只有地址 1 的电机会回复确认，所以库默认“只发不等待”。 如果总线上没有地址 1，等待应答会超时。

4.6 定时返回（可选）

// 让电机每 20ms 主动返回一次实时位置（0x36）
motor.SetTimedReport(0x36, 20);

// 停止返回
motor.StopTimedReport(0x36);

定时返回的数据会通过 ZdtSerialBus.FrameReceived / ZdtMotor.FrameReceived 收到，格式和对应读取命令一致。定时返回很密集时，不建议再同时高频轮询。

SetStiffness(value, store)0x4B 0x57Emm 积分限幅 / X 刚性系数

6.2 参数示例

// 闭环最大电流 3000mA，并写入驱动器
motor.SetClosedLoopCurrent(3000, store: true);

// 回零参数：单圈就近、CW、30RPM、超时 10s、碰撞检测 300RPM/800mA/60ms
motor.SetHomingParameters(new ZdtHomingParameters
{
    Mode = ZdtHomingMode.Nearest,
    Direction = ZdtDirection.Cw,
    SpeedRpm = 30,
    TimeoutMs = 10000,
    CollisionSpeedRpm = 300,
    CollisionCurrentMa = 800,
    CollisionTimeMs = 60,
    PowerOnAutoHome = false
}, store: true);

// 读取当前回零参数
ZdtHomingParameters hp = motor.ReadHomingParameters();

6.3 关于 store（是否存储）

store: true 会把参数写入驱动器掉电存储区。参数页的“保存”按钮用 true； 调试时频繁试参数建议用 false（只改 RAM），调好后再保存 true，减少 Flash 擦写。

7. Emm5.0 与 X 固件差异

7.1 如何识别

现象固件
小屏第二行显示角度误差 0.00err，绿灯常亮Emm5.0（出厂默认）
小屏第二行显示实时角度 0.0°，绿灯 1 秒闪 1 次X 固件

创建电机对象时必须选对：bus.CreateMotor(1, ZdtFirmware.Emm) 或 ZdtFirmware.X。选错时速度/位置命令格式不同，驱动器通常返回 E2。

7.2 主要差异

项目Emm5.0X
速度模式速度 RPM，加速度 0-255 档位速度 0.1RPM，加速度 RPM/s
位置模式脉冲数，运动模式 0/1/20.1°；直通 0xFB / 梯形 0xFD
力矩模式无有（0xF5 / 0xC5）
位置限流无有（0xCB / 0xCD）
角度读取0-65535 一圈0.1°
速度读取RPM0.1RPM
误差读取0-65535 一圈0.01°
快速位置0xF1 + 0xFC（脉冲）0xF1 + 0xFC（0.1°）

7.3 切换固件后要做什么

  1. 驱动器菜单 FWType 切换固件；
  2. 重新上电；
  3. 空载重新校准编码器；
  4. 上位机创建电机对象时改 ZdtFirmware；
  5. 如果改了细分或电机类型，同步修改 motor.Microstep / MotorStepAngleDegrees。

8.2 Response 菜单与 WaitForAck

Response行为库设置
Receive（默认）控制命令返回 0x02；读命令正常返回数据默认即可
None控制命令不返回任何帧bus.WaitForAck = false;
Reached只返回到位/回零完成 0x9F位置命令会等到 0x9F 才返回 Completed
Both0x02 + 0x9F默认即可，9F 通过事件收到
Other位置命令返回到位，其他控制命令返回 0x02默认即可
如果按钮点下去一直提示“等待电机应答超时”，先检查驱动器 Response。 设为 None 时库必须关闭 WaitForAck，否则会等满 200ms 后抛超时。

9. 常见问题排查

现象可能原因与处理
打开串口失败串口被其他软件占用（JCom、上位机、Arduino 串口监视器）；USB 转串口驱动未装；COM 号选错。关闭其他软件、重新插拔、在设备管理器确认 COM 号。
所有命令都超时波特率不一致；电机地址不对；A/B 接反；TX/RX 没交叉；没有共地；驱动器 Checksum 不是 0x6B 而库里没改。先只读 ReadVersion() 验证。
返回 E2参数超范围；固件类型选错（Emm 命令发给了 X 固件）；开环模式触发校准；触发了低压/堵转/过流/过温保护。用 ReadHomingStatus() 看保护位。
返回 EE命令格式/长度错误；自定义 SendRaw 时数据长度不对；固件类型不匹配。先用库封装好的方法验证。
使能后电机不转速度太小；加速度为 0 但速度没给；处于开环且电流太小；机械卡死；驱动未校准。先 ReadMotorStatus() 看是否使能、是否堵转。
运动方向反了改 SetMotorDirection()，或调换电机 A+/A-、B+/B- 其中一组线序后重新校准。
位置不准/丢步没有空载校准；细分/电机类型设置不对；负载超力矩；加速度太大；闭环最大电流太小。先低速空载测试。
多机通讯冲突地址重复；RS485 没有共地/终端电阻；只有地址 1 回复 0xAA 多电机命令；广播命令不要用于读参数。
回零失败回零模式与接线不匹配；碰撞检测电流/时间设置不合理；限位开关电平不对；超时时间太短。用 ReadHomingStatus() 看 Org_CF/Org_SF。
界面卡顿在 UI 线程里循环读串口。改用 ZdtPoller；按钮命令本身很短，可以同步调用。
数据偶尔错帧USB 转 485 质量差/线太长/波特率太高；增加 InterCommandDelayMs；降低波特率；加终端电阻；检查共地。

11. 安全与使用注意事项

硬件安全：
  • 接线、拔插电机线/通讯线前先断电；带电拔插可能损坏驱动板。
  • 电源建议 12/24V 3A 以上，电压不要超过驱动器版本上限（常规 29V / 高压 48V）。
  • 电机相电流、闭环最大电流不要盲目拉满；堵转和长时间大电流会严重发热。
  • 云台俯仰轴失能前确认机械结构不会因重力下坠；调试时先空载、低速、低电流。
  • RS485 长距离要共地、A/B 双绞、必要时加 120Ω 终端电阻。

11.1 软件注意事项

  • 不要在 WinForms UI 线程里循环读串口；用 ZdtPoller。
  • 不要频繁写 Flash；调试参数用 store: false，确定后再保存。
  • 修改地址、固件类型、控制模式后，及时同步 motor.Address / Firmware，并尽量停机操作。
  • 位置模式和回零指令执行期间，避免同时大量读参数，以免命令排队导致动作延迟。
  • 上位机应有“立即停止”按钮，并保证串口异常时能关闭输出。
  • 第一次接实物：先只读版本/状态/位置，确认通信正常，再做使能、低速、小角度运动。

11.2 本库的验证边界

本库的协议组帧、拆帧、CRC-8 表、手册示例帧已通过 62 项离线自测； 但尚未在真实电机上验证串口打开、驱动器应答时序和实际运动。 第一次使用请按“读版本 → 读状态 → 使能 → 低速小角度 → 回零”的顺序逐级验证， 并先在空载、低压、小电流条件下测试。
